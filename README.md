# Світло — калькулятор автономності

Рабочая статическая версия калькулятора резервного питания для домашнего рабочего места. Интерфейс на украинском. HTML, CSS и JavaScript без зависимостей, сборки и серверной части.

## Файлы

- index.html — страница.
- style.css — оформление и адаптивная верстка.
- app.js — интерфейс и обработка ввода.
- calculation.mjs — независимая функция расчетов.
- stations.mjs — проверенные характеристики моделей и правила подбора.
- station-picker.mjs — карточки моделей и фильтр.
- tests/stations.test.mjs — проверки подбора (запуск: `node --test tests/stations.test.mjs`).

## Запуск локально

В терминале перейдите в распакованную папку svitlo и выполните:

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080 . Остановить сервер: Ctrl+C.
Открытие index.html двойным щелчком не подходит: приложение использует JavaScript-модули.

## GitHub

Создайте пустой репозиторий svitlo, без автоматически добавленного README. В распакованной папке выполните команды ниже. Вместо YOUR_USERNAME укажите свой логин GitHub. Видимость репозитория выберите самостоятельно: public раскрывает исходный код, private сохраняет его закрытым.

```bash
git init -b main
git add .
git commit -m "Initial calculator"
git remote add origin https://github.com/YOUR_USERNAME/svitlo.git
git push -u origin main
```

Для push требуется авторизация GitHub через credential manager, GitHub CLI или другой поддерживаемый способ. Не записывайте токены в код или remote URL.

## Другой статический хостинг

Публикуется папка, содержащая index.html, style.css, app.js, calculation.mjs, stations.mjs и station-picker.mjs. Сборка не требуется. Хостинг должен отдавать .mjs с JavaScript MIME type. Приложению не нужны переменные окружения, база данных или секреты.

## Расчет и ограничения

Нагрузка P = сумма мощности выбранных приборов × их количество.
Энергия E = P × часы.
Номинальная емкость = E / (эффективность / 100) / (1 - остаток заряда / 100), округление вверх до 10 Вт·ч.
Автономность = номинальная емкость × эффективность × доступная доля заряда / P.
Ориентир непрерывной выходной мощности = P × 1.25, округление вверх до 10 Вт.

Начальные 85% эффективности и 10% остатка — редактируемые предположения, не данные конкретной станции. Начальные мощности приборов — примеры. Собственное потребление станции отдельно не моделируется. Расчет рассчитан на электронику и освещение, не моделирует пусковые токи двигателей. Не является проектом подключения оборудования.

## Что пока отсутствует

Актуальные цены, остатки в магазинах, аналитика посетителей, сбор заявок и платежи не подключены. Все вычисления происходят в браузере. Ничего не отправляется на сервер приложения и не сохраняется между перезагрузками. Сам хостинг может вести стандартные журналы запросов.

## Быстрый тест спроса

Дайте 5–10 людям, которые выбирают зарядную станцию, задание рассчитать автономность своего рабочего места. Наблюдайте, могут ли они закончить без подсказок. Спросите, что они выбрали бы по результату и какой информации не хватает до покупки. Записывайте наблюдения отдельно — встроенного сбора ответов нет.


## Подбор конкретной станции

Встроенный каталог содержит 6 конкретных европейских версий EcoFlow, Anker и BLUETTI. У каждой записи есть ссылка на страницу производителя. Емкости и постоянные AC-мощности проверены 08.09.2026. Сравниваются базовые конфигурации без дополнительных батарей. Цены и наличие не отслеживаются.

Модель проходит подбор, если расчетное время работы достигает цели и постоянная AC-мощность не меньше ориентира `result.power` (нагрузка +25%, округленная вверх до 10 Вт). Для сравнения времени используется неокругленное значение, а не округленная емкость из заголовка. Surge, X-Boost и Power Lifting не подменяют постоянную мощность. При превышении постоянной мощности оценка автономности не показывается. Если моделей нет или ввод неверен, интерфейс показывает соответствующее состояние и не сохраняет прошлые рекомендации.

Эффективность и остаток заряда общие для всех моделей. Расчет не учитывает индивидуальные кривые КПД, потребление инвертора, число разъемов, пусковые токи, зарядку в режиме сквозного питания или переключение ДБЖ. Это предварительное сравнение параметров для электроники и освещения. Павербанки и отдельные аккумуляторы пока не входят в автоматический подбор.

Для обновления каталога отредактируйте `stations.mjs` и дату `checkedOn`, сверив каждую конкретную версию с источником. Каталог намеренно не объявляет лучшую или самую дешевую модель.
